# MCP Resources

The server exposes the following resource handlers that resolve `surefinance://` URIs:

- `surefinance://accounts/{id}` — Fetch account details with balance history.
- `surefinance://transactions/{id}` — Fetch a single transaction record.
- `surefinance://budgets/{id}` — Fetch budget details with period breakdown.
- `surefinance://holdings/{id}` — Fetch investment holding details.
